1. HTML 報告自動化部署

我們經歷了多種方案的嘗試，最終確立了最適合免費且穩定的流程：

  • 嘗試一：Cloudflare Tunnel/Cloudflared - 雖然穩定，但需要複雜的帳號綁定與 API Token 設定。
  • 嘗試二：ngrok - 免費版需要註冊並取得 Auth Token，且連結有時效性。
  • 最終方案：GitHub Pages - 透過 gh-pages 分支配合 GitHub Pages 功能，達成永久連結與自動化更新。
操作重點：將 Repository 設為 Public，並在 Settings > Pages 選擇 gh-pages 分支。

2. SSH 金鑰與自動化環境

為了讓 Claw 能在背景自動推送程式碼，我們設定了 Mac mini 的 SSH 環境：

  • 產生專屬 SSH Key: ~/.ssh/id_ed25519_github
  • 設定 Git Remote 為 SSH 模式: git@github.com:ni8711424-svg/Openclaw-Html.git
  • 利用 ssh-add 確保金鑰載入，解決 Host key verification 問題。

3. Claw 操作規範（重要）

根據 Sam 的指令，Claw 必須嚴格遵守以下輸出格式：

  • 連結格式： 所有提供的網址或連結，前後「不加引號」或「方括號」，確保在 Discord 等通訊軟體中可直接點選。
  • 主動執行： 除非涉及安全紅線（如登入個人帳號），否則 Claw 應直接在終端機執行指令，而非提供指令給 Sam 手動操作。
  • 表格呈現： 優先使用 HTML 格式呈現表格資料。
