1. HTML 部署策略演進

  • Cloudflare Tunnel： 嘗試過，但 API Token 權限設定複雜。
  • ngrok： 連結有時效性，不適合長期展示。
  • GitHub Pages（最終方案）： 設為 Public Repo 並使用 gh-pages 分支，達成永久連結。

2. SSH 金鑰與自動化

  • 產生專屬金鑰: ~/.ssh/id_ed25519_github
  • 設定 Git Remote: git@github.com:ni8711424-svg/Openclaw-Html.git
  • 解決 Host key verification 問題，實現背景自動推送。

3. Claw 操作規範

  • 連結格式： 網址前後不加引號或方括號，確保可直接點選。
  • 主動執行： 直接在終端機執行指令，減少 Sam 的手動操作。
