Claw 工作回顧與技術總結

日期： 2026-04-04 至 2026-04-05 | 對象： Sam (美味跳蚤)

1. HTML 部署策略演進

  • Cloudflare Tunnel： 初期嘗試，但 API Token 權限複雜，且在 Discord 環境下無法完成互動授權。
  • ngrok： 連結有時效性，不適合長期展示報告。
  • GitHub Pages（最終方案）： 將 Repo 設為 Public，並透過 gh-pages 分支。此方案永久免費、連結固定。

2. SSH 金鑰與自動化環境

  • 金鑰產生： 建立專屬金鑰 ~/.ssh/id_ed25519_github。
  • Remote 設定： 指向 git@github.com:ni8711424-svg/Openclaw-Html.git。
  • 自動化修正： 透過 ssh-add 與 StrictHostKeyChecking=no 解決背景推送的驗證問題。

3. Claw 操作規範（重要）

  • 連結格式： 網址前後不加引號或方括號，確保在 Discord 可直接點選。
  • 主動執行： 除非涉及安全紅線，否則直接在終端機執行指令，不勞煩 Sam 動手。
  • 表格呈現： 優先使用 HTML 格式呈現。
